# Corredor Logística — site

Site de uma página para uma empresa de logística, feito em HTML, CSS e JavaScript puros (sem dependências nem etapa de build).

## Seções

- **Início**: túnel de luz animado em WebGL (adaptado do componente LightTunnel, do React Bits) que segue o mouse e envia um pulso ao clicar
- **Serviços**: transporte rodoviário, armazenagem, distribuição urbana e logística reversa
- **Como funciona**: as quatro etapas da carga
- **Cobertura**: centros de distribuição, números da operação e mapa das rotas
- **Rastreamento**: busca por código (resultado de demonstração)
- **Cotação**: formulário de pedido de cotação

Entre as seções há transições animadas, e o conteúdo de cada uma aparece ao rolar a página. Quem ativa "reduzir movimento" no sistema vê o site sem animações.

## Como abrir

Abra o `index.html` no navegador. Para publicar, ative o GitHub Pages em **Settings → Pages**, com a branch `main` e a pasta raiz.

## Antes de publicar

- Troque o nome, o telefone, o e-mail, o endereço e os números pelos dados reais da empresa.
- Ligue o formulário de cotação a um e-mail ou sistema. Hoje ele só valida os campos e mostra um resumo.
- O rastreamento mostra um resultado de exemplo e precisa ser conectado ao sistema de rastreamento da empresa.
